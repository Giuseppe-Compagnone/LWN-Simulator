# LWN Simulator UI

Welcome to the **LWN Simulator UI** component library.

This library provides the reusable UI components, design tokens, and theming system used throughout the **LWN Simulator**, a Next.js application for simulating and visualizing LoRaWAN networks.

Its purpose is to ensure a consistent, accessible, and maintainable user experience across the entire application.

---

## What this library provides

In addition to reusable React components, the library includes:

- 🎨 **Light and Dark themes**
- 🖋️ **Typography system** with shared font definitions
- 📐 **Responsive design tokens** and breakpoints
- 🎯 **Design tokens** for colors, spacing, sizing, and typography
- 🧩 Reusable and composable UI components
- 📖 Interactive documentation powered by Storybook
- 💙 TypeScript-first APIs
- ♿ Accessibility-oriented components

---

## Theming

The library provides a centralized theming system that allows applications to switch seamlessly between **Light** and **Dark** modes while maintaining a consistent visual language.

The theme also exposes shared design tokens, including:

- Color palette
- Typography
- Font families
- Font sizes
- Spacing
- Border radius
- Responsive breakpoints

---

## Responsive Design

Components are designed to work across different screen sizes using a shared responsive system.

Common layout values, typography scales, and spacing are driven by design tokens to ensure consistency across desktop, tablet, and mobile experiences.

---

## Development

Run Storybook locally:

```bash
yarn storybook
```

Build the component library:

```bash
yarn build
```

Generate the static Storybook documentation:

```bash
yarn build-storybook
```

---

## Design Principles

The library is built around a few core principles:

- **Consistency** – a unified design language across the simulator.
- **Reusability** – components should be composable and easy to extend.
- **Scalability** – shared themes and design tokens simplify future development.
- **Type Safety** – fully typed APIs with TypeScript.
- **Accessibility** – components are designed with usability in mind.
- **Maintainability** – a centralized source of truth for UI patterns and styles.
