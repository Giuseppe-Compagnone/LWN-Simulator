# Server Edition

La Server Edition exécute le backend et publie l'interface dans un navigateur.

1. Démarrez le serveur.
2. Ouvrez son adresse dans le navigateur.
3. Configurez et exécutez les simulations.

La Desktop Edition peut également se connecter à une Server Edition active. Les clients reliés au même backend partagent le matériel, les contrôles et les journaux en temps réel.
