# Configuration

La configuration est enregistrée dans le profil actif. Le sélecteur supérieur permet de changer de réseau sans mélanger appareils, passerelles ou historique.

Pour un serveur distant, saisissez son adresse au démarrage de la Desktop Edition. Plusieurs onglets peuvent utiliser le même backend.

Configurez l'adresse et le port du Gateway Bridge dans Matériel, puis enregistrez : les réglages s'appliqueront au prochain démarrage de simulation.
