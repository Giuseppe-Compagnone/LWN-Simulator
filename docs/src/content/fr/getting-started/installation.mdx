# Installation

Choisissez l'édition selon votre usage.

La **Desktop Edition** s'installe sur votre ordinateur et peut démarrer un serveur local ou se connecter à un serveur distant. La **Server Edition** démarre le backend et fournit l'interface dans un navigateur, ce qui convient à un serveur dédié ou à plusieurs utilisateurs.

## Premier accès

1. Démarrez l'application ou le serveur.
2. Choisissez le serveur local ou saisissez l'adresse distante.
3. Créez ou sélectionnez un profil.
4. Ouvrez [Matériel](../hardware) pour préparer le réseau.

Les distributions incluent les dépendances nécessaires.
