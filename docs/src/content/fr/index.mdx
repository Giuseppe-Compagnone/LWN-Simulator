# LoRaWAN Simulator

Bienvenue dans la documentation officielle de **LoRaWAN Simulator**.

L'application permet de créer, configurer et exécuter des simulations de réseaux LoRaWAN depuis une interface graphique. Elle existe en édition Desktop et en édition Server, avec le même espace de simulation.

<Callout type="info" emoji="💡">
  Pour commencer, consultez [Installation](./getting-started/installation), puis le [guide de simulation](./simulation).
</Callout>

## Parcours recommandé

1. Installez l'édition adaptée à votre environnement.
2. Créez ou sélectionnez un profil réseau.
3. Ajoutez les appareils et les passerelles dans Matériel.
4. Lancez la simulation et observez les métriques, les liens et les journaux.
