# Passerelles

Une passerelle reçoit les paquets des appareils couverts et les transmet au backend ou au transport UDP.

Définissez le nom, le Gateway EUI, le type virtuel ou réel, la position, la portée, l'état activé et, pour une passerelle réelle, l'adresse IPv4 et le port. Plusieurs passerelles peuvent recevoir un même uplink. Elles ne communiquent pas directement entre elles.
