# LoRaWAN Simulator

Willkommen in der offiziellen Dokumentation des **LoRaWAN Simulator**.

Mit der Anwendung lassen sich LoRaWAN-Netzwerke über eine grafische Oberfläche erstellen, konfigurieren und simulieren. Es gibt eine Desktop Edition und eine Server Edition; beide verwenden denselben Simulationsbereich.

<Callout type="info" emoji="💡">
  Wenn Sie zum ersten Mal starten, beginnen Sie mit [Installation](./getting-started/installation) und lesen Sie danach den [Simulationsleitfaden](./simulation).
</Callout>

## Empfohlener Ablauf

1. Installieren Sie die passende Edition.
2. Erstellen oder wählen Sie ein Netzwerkprofil.
3. Fügen Sie Geräte und Gateways unter Hardware hinzu.
4. Starten Sie die Simulation und prüfen Sie Metriken, Verbindungen und Protokolle.

## Bereiche

- [Erste Schritte](./getting-started/installation): Installation, Verbindung und Fehlerbehebung.
- [Profile](./profiles): unabhängige Netzwerke mit getrennten Einstellungen und Historien.
- [Hardware](./hardware): Geräte, Gateways und Bridge.
- [Simulation](./simulation): Steuerung, Datenverkehr und Live-Metriken.
- [Protokolle](./logs): Simulationshistorie und Ereignisse je Objekt.
