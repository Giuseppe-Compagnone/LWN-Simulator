# Hardwareverwaltung

Unter Hardware wird die Topologie des aktiven Profils festgelegt. Konfigurieren Sie Geräte, Gateways und Gateway Bridge vor dem Simulationsstart.

Position, Antennenreichweite, Funkparameter und Aktivierungsstatus beeinflussen Abdeckung und Kartenverbindungen. Eine Verbindung erscheint nur, wenn das Gerät vom Gateway empfangen werden kann.

Siehe [Geräte](./devices), [Gateways](./gateways) und [Gateway Bridge](./gateway-bridge).
