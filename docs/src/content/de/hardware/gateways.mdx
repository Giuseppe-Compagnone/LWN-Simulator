# Gateways

Ein Gateway empfängt Pakete abgedeckter Geräte und leitet sie an das Backend oder den UDP-Transport weiter.

Definieren Sie Name, Gateway EUI, virtuellen oder realen Typ, Position, Reichweite, Aktivierungsstatus sowie bei realen Gateways IPv4-Adresse und Port. Mehrere Gateways können denselben Uplink empfangen. Gateways kommunizieren nicht direkt miteinander.
