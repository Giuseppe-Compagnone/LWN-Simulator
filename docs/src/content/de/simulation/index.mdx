# Simulationen

Eine Simulation nutzt das aktive Profil, erzeugt LoRaWAN-Datenverkehr und zeigt die Wirkung der Konfiguration.

Legen Sie Geschwindigkeit und optionalen Seed fest und wählen Sie **Start simulation**. Die Geschwindigkeit ändert die simulierte Zeit; derselbe Seed macht ein Szenario wiederholbar. Während der Ausführung können Sie pausieren, fortsetzen, stoppen und die Geschwindigkeit ändern.

Das Dashboard zeigt Uptime, Packet Success, Funkstatus, Gateways, Ereignisse, Runtime-Geräte und Kartenverbindungen. Die [Konsole](./dashboard) sendet Uplinks, Downlinks und MAC-Befehle.
