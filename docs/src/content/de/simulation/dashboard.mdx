# Dashboard und Konsole

Das Dashboard bündelt Karte, Metriken, Runtime-Status und Ereignisstream.

Unter **Uplink** planen Sie eine Nachricht für das ausgewählte Gerät. Unter **Downlink** senden Sie UTF-8- oder Base64-Payload, wählen FPort 1 bis 223, Data Rate sowie confirmed und ACK. Unter **MAC command** wählen Sie einen Befehl und seine Parameter.

LinkMarker zeigen aktuelle, gültige Kommunikation. Die ursprüngliche Kartenposition bleibt erhalten, während neue Ereignisse eintreffen.
