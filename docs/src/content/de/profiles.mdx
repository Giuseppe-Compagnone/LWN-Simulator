# Netzwerkprofile

Jedes Profil enthält ein unabhängiges Netzwerk. Geräte, Gateways, Bridge-Einstellungen und Simulationshistorie werden nicht mit anderen Profilen geteilt.

## Profile verwalten

Mit dem Selektor in der oberen Leiste wechseln Sie das Netzwerk. Das Menü ermöglicht das Erstellen eines leeren Profils, Umbenennen, Exportieren in eine einzelne JSON-Datei, Importieren als neues Profil und Löschen.

Jedes Profil besitzt eine eindeutige interne Kennung. Der gewählte Name dient nur zur Anzeige.

## Import und Export

Der Export enthält die Netzwerkkonfiguration und die verfügbare Historie. Ein Import erstellt immer ein neues Profil und überschreibt niemals das ausgewählte Profil.

## Gemeinsame Simulation

Das Backend führt immer nur eine Simulation aus. Während eine andere Simulation aktiv ist, bleibt die Start-Schaltfläche deaktiviert und die Oberfläche zeigt den Grund an. Beenden Sie die aktive Simulation, bevor Sie eine neue starten.
