# Fehlerbehebung

Wenn der Server nicht erreichbar ist, prüfen Sie Adresse, Port, Firewall und Backend-Status. Pro Backend ist nur eine Simulation erlaubt; beenden Sie eine Simulation in einem anderen Profil, bevor Sie eine neue starten.

Wenn der Bridge keinen Datenverkehr empfängt, prüfen Sie Aktivierung, Adresse und Port des Packet Forwarders. Wenn Protokolle nicht aktualisiert werden, prüfen Sie die Verbindung und laden Sie die Seite neu.
