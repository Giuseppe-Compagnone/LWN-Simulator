# Server Edition

Die Server Edition führt das Backend aus und veröffentlicht die Oberfläche über einen Browser.

1. Starten Sie den Server.
2. Öffnen Sie seine Adresse im Browser.
3. Konfigurieren und starten Sie Simulationen.

Die Desktop Edition kann sich ebenfalls mit einer aktiven Server Edition verbinden. Alle Clients am selben Backend teilen Hardware, Steuerung und Live-Protokolle.
