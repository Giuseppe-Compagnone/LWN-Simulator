# Installation

Wählen Sie die Edition passend zu Ihrem Einsatz.

Die **Desktop Edition** wird auf dem Computer installiert und kann einen lokalen Server starten oder sich mit einem entfernten Server verbinden. Die **Server Edition** startet das Backend und stellt die Oberfläche im Browser bereit.

## Erster Zugriff

1. Starten Sie Anwendung oder Server.
2. Wählen Sie den lokalen Server oder geben Sie die entfernte Adresse ein.
3. Erstellen oder wählen Sie ein Profil.
4. Öffnen Sie [Hardware](../hardware), um das Netzwerk vorzubereiten.

Die Distributionen enthalten die erforderlichen Abhängigkeiten.
