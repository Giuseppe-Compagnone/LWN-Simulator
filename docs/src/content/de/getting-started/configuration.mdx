# Konfiguration

Die Konfiguration wird im aktiven Profil gespeichert. Mit dem Selektor oben wechseln Sie zwischen getrennten Netzwerken, Gateways und Historien.

Für einen entfernten Server geben Sie dessen Adresse beim Start der Desktop Edition ein. Mehrere Tabs können dasselbe Backend nutzen.

Adresse und Port des Gateway Bridge werden unter Hardware eingestellt. Speichern Sie die Werte; sie gelten ab dem nächsten Simulationsstart.
