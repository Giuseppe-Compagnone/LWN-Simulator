# Desktop Edition

The Desktop Edition is the main way to interact with LoRaWAN Simulator.

When the application starts, you can choose how to connect to a simulation server.

## Local Server

In this mode, the application automatically starts a local server on your computer.

This option is recommended for:

- Development
- Testing
- Learning
- Offline usage

No additional configuration is required.

## Remote Server

In this mode, the Desktop Edition connects to an existing server.

Simply enter the server address and establish the connection.

This configuration is useful when simulations are hosted on another machine or shared among multiple users.

## Switching modes

You can choose the desired connection mode each time the application starts.
