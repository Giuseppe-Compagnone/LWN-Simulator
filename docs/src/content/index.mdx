# LoRaWAN Simulator

Welcome to the official documentation of **LoRaWAN Simulator**.

LoRaWAN Simulator is an application designed to simplify the creation, configuration, and execution of LoRaWAN network simulations through an intuitive graphical interface.

The project is available in two editions:

- **Desktop Edition** – A desktop application that provides a native user interface and can either start a local simulation server or connect to a remote one.
- **Server Edition** – A standalone application that runs the simulation server and provides the web interface accessible through a browser.

Both editions allow users to interact with the simulator. The main difference is how the application is deployed and accessed.
