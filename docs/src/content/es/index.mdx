# LoRaWAN Simulator

Bienvenido a la documentación oficial de **LoRaWAN Simulator**.

La aplicación permite crear, configurar y ejecutar simulaciones de redes LoRaWAN desde una interfaz gráfica. Incluye una edición de escritorio y una edición de servidor, ambas con el mismo espacio de simulación.

<Callout type="info" emoji="💡">
  Si es tu primera vez, empieza por [Instalación](./getting-started/installation) y continúa con la [guía de simulación](./simulation).
</Callout>

## Recorrido recomendado

1. Instala la edición adecuada para tu entorno.
2. Crea o selecciona un perfil de red.
3. Añade dispositivos y gateways desde Hardware.
4. Inicia la simulación y revisa métricas, enlaces y registros.
