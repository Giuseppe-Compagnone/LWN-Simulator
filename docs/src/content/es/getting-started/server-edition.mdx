# Server Edition

La Server Edition ejecuta el backend y publica la interfaz mediante un navegador.

1. Inicia el servidor.
2. Abre su dirección en el navegador.
3. Configura y ejecuta las simulaciones desde la interfaz web.

La Desktop Edition también puede conectarse a una Server Edition activa. Todos los clientes conectados al mismo backend comparten hardware, controles y registros en tiempo real.
