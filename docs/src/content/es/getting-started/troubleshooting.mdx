# Solución de problemas

Si el servidor no responde, comprueba la dirección, el puerto, el firewall y que el backend esté activo. Solo se permite una simulación por backend: detén la simulación de otro perfil antes de iniciar una nueva.

Si el bridge no recibe tráfico, verifica que esté habilitado y que la dirección y el puerto coincidan con el packet forwarder. Si los registros no se actualizan, comprueba la conexión y recarga la página.
