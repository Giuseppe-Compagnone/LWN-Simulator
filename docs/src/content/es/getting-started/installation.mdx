# Instalación

Elige la edición según el modo en que quieras usar el simulador.

La **Desktop Edition** se instala en tu sistema y puede iniciar un servidor local o conectarse a uno remoto. La **Server Edition** inicia el backend y ofrece la interfaz en un navegador, por lo que es adecuada para un servidor dedicado o para varios usuarios.

## Primer acceso

1. Inicia la aplicación o el servidor.
2. Selecciona el servidor local o introduce la dirección remota.
3. Crea o selecciona un perfil.
4. Abre [Hardware](../hardware) para preparar la red.

Las distribuciones incluyen las dependencias necesarias; no hace falta instalar herramientas de desarrollo aparte.
