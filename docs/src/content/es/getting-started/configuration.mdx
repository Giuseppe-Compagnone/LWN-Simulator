# Configuración

La configuración se guarda en el perfil activo. Cambia de perfil desde el selector superior para mantener separadas las redes, los gateways y el historial.

Para un servidor remoto introduce su dirección al iniciar la Desktop Edition. Varias pestañas pueden conectarse al mismo backend y ver los cambios compartidos.

Configura la dirección y el puerto del Gateway Bridge en Hardware. Guarda los cambios: se aplicarán al iniciar la siguiente simulación.
