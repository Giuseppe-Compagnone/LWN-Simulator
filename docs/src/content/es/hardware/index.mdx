# Gestión de hardware

Hardware define la topología del perfil actual. Configura dispositivos, gateways y el Gateway Bridge antes de iniciar una simulación.

La posición, el alcance de antena, los parámetros de radio y el estado habilitado influyen en la cobertura y en los enlaces mostrados en el mapa. Un enlace solo aparece cuando el dispositivo puede ser recibido por el gateway.

Consulta [Dispositivos](./devices), [Gateways](./gateways) y [Gateway Bridge](./gateway-bridge) para los detalles.
