# Gateways

Un gateway recibe los paquetes de los dispositivos cubiertos y los reenvía al backend o al transporte UDP.

Define nombre, Gateway EUI, tipo virtual o real, posición, alcance, estado habilitado y, para gateways reales, dirección IPv4 y puerto. Varios gateways pueden recibir el mismo uplink; el simulador evalúa distancia, radio, colisiones y cobertura. Los gateways no se comunican directamente entre sí.
