# Simulaciones

Una simulación usa el perfil actual para producir tráfico LoRaWAN y mostrar el efecto de su configuración.

Define la velocidad y una semilla opcional, y pulsa **Start simulation**. La velocidad cambia el tiempo simulado; la misma semilla permite repetir el escenario. Durante la ejecución puedes pausar, reanudar, detener y cambiar la velocidad.

La dashboard muestra uptime, packet success, radio, gateways, eventos, dispositivos runtime y enlaces del mapa. Usa la [consola](./dashboard) para enviar uplinks, downlinks y comandos MAC.
