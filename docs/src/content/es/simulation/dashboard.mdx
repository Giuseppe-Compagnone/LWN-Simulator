# Dashboard y consola

La dashboard reúne el mapa, las métricas, el estado runtime y el stream de eventos.

En **Uplink** programa un mensaje para el dispositivo elegido. En **Downlink** envía un payload UTF-8 o Base64, selecciona un FPort de 1 a 223, data rate y las opciones confirmed y ACK. En **MAC command** elige un comando y completa sus parámetros.

Los LinkMarker representan comunicaciones recientes y válidas. La posición inicial del mapa se conserva mientras llegan nuevos eventos.
