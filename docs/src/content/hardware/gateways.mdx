# Gateways

A gateway is the network-side endpoint that forwards LoRaWAN traffic. The
simulator supports two gateway types. Both share their identity and geographic
properties, while the connectivity settings depend on whether the gateway is
virtual or real.

## Common properties

| Field | Meaning | User-visible rules |
| --- | --- | --- |
| `id` | Internal unique identifier. | Generated by the server; read-only. |
| `active` | Whether the gateway is enabled. | Available when editing the gateway. |
| `name` | Friendly name shown in lists, details, and map tooltips. | Required. |
| `type` | Connectivity model used by the gateway. | `virtual` or `real`; it determines the conditional fields. |
| `macAddress` | Network interface MAC address. | Required. It is generated automatically during creation and is kept separately from the Gateway EUI. |
| `gatewayEUI` | LoRaWAN gateway identifier. | Required hexadecimal value with exactly 16 characters. It is generated automatically during creation and cannot be changed while editing. |
| `latitude` | North/south position used by the map. | Decimal degrees from `-90` to `90`. |
| `longitude` | East/west position used by the map. | Decimal degrees from `-180` to `180`. |
| `altitude` | Height above sea level. | Numeric value in meters. |

The MAC address and Gateway EUI identify different things and must not be
treated as interchangeable values: the MAC address identifies the network
interface, while the Gateway EUI identifies the LoRaWAN gateway.

## Virtual gateways

Select `virtual` for a gateway implemented by the simulator rather than an
external network-connected station.

| Field | Meaning | Accepted value |
| --- | --- | --- |
| `keepAlive` | Interval used by the virtual gateway to remain connected. | Required for virtual gateways; positive integer in seconds. |

The create form only shows this field when the gateway type is virtual.

## Real gateways

Select `real` when the gateway represents an external station reachable over
the network.

| Field | Meaning | Accepted value |
| --- | --- | --- |
| `gatewayIPv4` | IPv4 address where the gateway can be reached. | Required for real gateways; valid IPv4 address. |
| `gatewayPort` | Network port exposed by the gateway. | Required for real gateways; integer from `1` to `65535`. |

The create form only shows these fields when the gateway type is real. The
gateway’s MAC address and Gateway EUI are still required for real gateways.

## Map and details

Selecting a gateway marker opens a tooltip containing its name, status, type,
Gateway EUI, and MAC address. Long identifiers are constrained to the tooltip
width so they remain readable without overflowing the map.

The gateway detail page groups the information into identity, connectivity,
and location sections. Type-specific values are omitted when they do not apply
to the selected gateway type.

## Editing rules

The type, MAC address, and Gateway EUI are identity-level properties. The form
keeps generated identifiers stable while editing. Use the edit page to change
the active state, name, location, or the settings associated with the selected
gateway type.
