# Configurazione

Il simulatore salva la configurazione nel profilo attivo. Usa il selettore superiore per cambiare rete senza mescolare device, gateway o cronologie.

## Server remoto

Inserisci l'indirizzo del server quando avvii la Desktop Edition. Più client possono collegarsi allo stesso backend e vedranno gli aggiornamenti condivisi.

## Persistenza

I profili e i log restano disponibili dopo il riavvio del backend. Esporta un profilo per conservarne una copia o trasferirlo su un'altra installazione.

## Gateway Bridge

Configura indirizzo e porta nella pagina dedicata di Hardware. Il bridge viene applicato alla successiva simulazione e deve essere attivato esplicitamente.
