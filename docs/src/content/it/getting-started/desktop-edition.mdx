# Desktop Edition

La Desktop Edition offre l'interfaccia nativa e può avviare automaticamente un server locale oppure collegarsi a uno remoto.

Usa il server locale per sviluppo, test, apprendimento o uso offline. Usa il server remoto quando le simulazioni sono ospitate su un'altra macchina o devono essere condivise.

La modalità di connessione può essere scelta ogni volta che l'applicazione viene avviata.
