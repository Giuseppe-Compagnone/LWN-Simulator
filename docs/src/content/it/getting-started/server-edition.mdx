# Server Edition

La Server Edition avvia il backend e rende disponibile l'interfaccia tramite browser.

1. Avvia il server.
2. Apri l'indirizzo locale o remoto nel browser.
3. Configura ed esegui la simulazione dall'interfaccia web.

La Desktop Edition può collegarsi a una Server Edition già attiva. Tutte le schede e i client collegati allo stesso backend condividono hardware, controlli e log in tempo reale.
