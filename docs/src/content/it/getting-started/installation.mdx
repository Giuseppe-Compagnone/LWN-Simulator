# Installazione

Scegli l'edizione in base a come vuoi usare il simulatore.

## Desktop Edition

Scarica il pacchetto per il tuo sistema operativo, installalo e avvia l'applicazione. All'avvio puoi usare un server locale oppure collegarti a un server già attivo.

## Server Edition

Avvia il server e apri l'indirizzo indicato nel browser. È l'opzione adatta a un server dedicato o a più utenti che condividono la stessa simulazione.

## Primo accesso

1. Avvia l'applicazione.
2. Seleziona il server locale o inserisci l'indirizzo del server remoto.
3. Crea o seleziona un profilo.
4. Vai in [Hardware](../hardware) per preparare la rete.

Le distribuzioni sono autonome: non è necessario installare separatamente Node.js, Go o altri strumenti di sviluppo.
