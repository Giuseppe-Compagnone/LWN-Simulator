# LoRaWAN Simulator

Benvenuto nella documentazione ufficiale di **LoRaWAN Simulator**.

L'applicazione consente di creare, configurare ed eseguire simulazioni di reti LoRaWAN tramite un'interfaccia grafica. Sono disponibili una Desktop Edition e una Server Edition; entrambe usano lo stesso spazio di simulazione.

<Callout type="info" emoji="💡">
  Se è la prima volta che usi il simulatore, parti da [Installazione](./getting-started/installation) e continua con la [guida alla simulazione](./simulation).
</Callout>

## Percorso consigliato

1. Installa l'edizione più adatta al tuo ambiente.
2. Crea o seleziona un profilo di rete.
3. Aggiungi device e gateway nella sezione Hardware.
4. Avvia la simulazione e controlla metriche, collegamenti e log.
