# Server Edition

The Server Edition runs the LoRaWAN Simulator server and provides the user interface through a web browser.

When started, it launches the simulation server and makes the application available locally or remotely depending on the network configuration.

## Accessing the application

After starting the Server Edition, the simulator can be accessed using a web browser.

The interface can be opened:

- Locally, from the same machine running the server.
- Remotely, from another machine connected to the same network or server address.

## Typical workflow

1. Start the Server Edition.
2. Open the simulator address in a web browser.
3. Configure and run simulations directly from the web interface.

## Desktop Edition connection

The Desktop Edition can also connect to a running Server Edition instance.

This allows using the native desktop application while relying on a remote simulation server.

## When should I use it?

The Server Edition is recommended when:

- The simulator needs to be hosted on a dedicated machine.
- Multiple users need access to the same simulation environment.
- The application needs to be accessed without installing the Desktop Edition.
