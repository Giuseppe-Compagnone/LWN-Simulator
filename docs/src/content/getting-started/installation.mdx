# Installation

LoRaWAN Simulator is available in two editions depending on your deployment requirements.

## Desktop Edition

The Desktop Edition is a native desktop application that provides access to the simulator through a dedicated user interface.

It can operate in two modes:

- **Local Mode**: starts a local simulation server automatically and connects to it.
- **Remote Mode**: connects to an already running Server Edition instance.

This edition is recommended for users who want a simple installation process and a standalone application experience.

## Server Edition

The Server Edition is a standalone application that runs the LoRaWAN Simulator server and provides the web interface required to interact with the simulator.

Once started, the application can be accessed through a web browser.

It can be used:

- Locally, by opening the interface from the same machine where the server is running.
- Remotely, by connecting from another machine through the server address.

The Server Edition is recommended for shared environments, dedicated deployments, and scenarios where multiple users need access to the same simulation instance.

## Choosing the right edition

| Scenario                           | Recommended Edition               |
| ---------------------------------- | --------------------------------- |
| Personal use                       | Desktop Edition or Server Edition |
| Local development and testing      | Desktop Edition                   |
| Access through a browser           | Server Edition                    |
| Shared simulations                 | Server Edition                    |
| Dedicated simulation environment   | Server Edition                    |
| Remote access from Desktop Edition | Server Edition                    |
